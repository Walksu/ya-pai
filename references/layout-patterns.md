# 版式结构说明

十套版式骨架的详细结构与组件排列顺序。骨架的定位、第一眼印象、适用场景见 tokens/layouts.md；本文件只讲「组件怎么排」。

## 通用骨架（按顺序）

```
开篇区      （眉题 / 封面 / 目录卡，视骨架而定）
引言区      （可选的 lead 段落或引言引用）
正文章节    h2 起，章节进场方式由骨架决定
结尾区      结语（可选）→ 收尾线 → 签名卡（强制）
```

## 结尾区

- 原文有结尾语/签名 → 保留；原文没有 → 用细线与正文分隔，不虚构 CTA。
- 每篇末尾**强制** F11c 作者签名卡；F13 留存卡仅用户明确要求或原文自带互动引导时加（默认关）。

## 规则

- 骨架决定「形状」，其余维度决定「皮肤」；两者自由组合。
- 同一篇只走一条骨架、只用一套变量与一族变体，不跨骨架混搭。
