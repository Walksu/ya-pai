## 面色板（tonal family）

面色板不只是「1 个 accent + 1 个浅底」，而是一组**同色系不同饱和度的色阶**，各自服务不同表面：纸底、墨、线、面色 A/B（图解面）、高亮条、结论卡底、强调。低饱和但层次丰富，是「优雅、低调但不简单」的主要来源。用法：

- 同篇仍只有一个 accent 做文字强调；surface-a / surface-b 只做图解面（重叠圆等），highlight 只做整句高亮条，summary-bg 只做结论卡底。
- 面色板是「推荐色板」的高级形态；普通色板依然可用，两者不混用。

### 面色板 token 兜底映射（普通色板时）

组件会引用 `{{SURFACE_A}}` / `{{SURFACE_B}}` / `{{HIGHLIGHT}}` / `{{SUMMARY_BG}}`；当用户选择的是普通色板（无这些 token）时，按下面规则回退，**禁止空引用或临场编色**：

| 面色板 token | 回退到 | 说明 |
|---|---|---|
| surface-a | accent-soft | 图解面色 A 用强调浅底 |
| surface-b | code-bg（浅色板）或 divider | 图解面色 B 用更浅的面 |
| highlight | accent-soft | 高亮条用强调浅底 |
| summary-bg | content-bg | 结论卡底用内容底 |

回退后的效果会接近「单 accent + 浅底」；要完整的多面色阶效果，建议改选纸绿/纸蓝/陶土三套面色板之一。

## 用法原则

- 60/30/10：内容底 60%、正文/标题 30%、强调色 10% 以内。
- accent 用于眉题、链接、关键短语、章节编号；不用 accent 做大面积底色。
- 正文与内容底对比度 ≥ 4.5:1；标题（≥24px 或 ≥18.66px 加粗）≥ 3:1；小字号次要文字（眉题/图注/页码，<14px）≥ 3:1。深色板下 accent 用亮铜 `#C9A26B` 而非暗色。
- 强调色锚点（全篇 ≤3 处的 accent 加粗）若低于 4.5:1 但 ≥3.5:1，可人工确认后保留；其余一律按上述门槛执行。
- 低饱和色板强调色偏暗，正文着色时加 `font-weight:600` 补偿。
- 跨气质使用时：暖米/低饱和 → 暖气质；冷灰/深色/高对比 → 冷气质。
- 面色板三套的冷暖：纸绿/陶土 → 暖或中性；纸蓝 → 冷。
