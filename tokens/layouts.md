# 版式骨架（layouts）

版式不是「宽度档」，而是**骨架规则**——它决定整篇文章的第一眼印象：开篇怎么进、章节怎么进场、引用/列表/图片怎么处理、怎么收尾。十套骨架可与其他任意维度（气质/色板/字体/标题风格/疏密/装饰/背景/功能）自由组合；选好骨架后，同一篇内不跨骨架混搭。

## L1 单栏流 flow

- 第一眼：干净的一列文字流，靠字号与留白分层，无卡片堆叠。
- 开篇：眉题 → 细线 → 正文直接进；不放封面卡。
- 章节进场：F3a/F3b/F3e（编号细线 / 水印数字 / 墨线方块），靠线或留白分隔。
- 引用/列表/图片：左竖线引用、圆点/编号列表、图片细线框，全部单列。
- 收尾：收尾线 → 签名卡。
- 容器 `max-width:560–660px`；适用：随笔、书评、观点、深度长文。

## L2 导读 + 章节流 guided

- 第一眼：开篇有一张「导航卡」，读者先看到本文看点，再进正文。
- 开篇：眉题/封面 → 目录卡（F2a/F2b/F2d，取前 3–6 章）→ 引言。
- 章节进场：F3a/F3c/F3i（编号 + 英文标签），结构感强。
- 引用/列表/图片：可上色块卡（L2 及以上）；列表编号圆标。
- 收尾：收尾线 → 签名卡（可加 F13 留存卡，默认关）。
- 容器 `max-width:660px`；适用：教程、清单、方法论、长文。

## L3 时间线式 timeline

- 第一眼：章节像一条时间轴，过去 → 现在 → 未来。
- 开篇：简短眉题直接进，或小封面；不放重目录。
- 章节进场：F3c 大数字 + 竖线（编号即时间节点）；章节之间可用细竖线连缀。
- 引用/列表/图片：按时间顺序的列表（F8b）为主，引用少用；图片作为「节点证据」。
- 收尾：结语章编号 ∞ → 收尾线 → 签名卡。
- 容器 `max-width:560–660px`；适用：演进史、案例复盘、项目回顾、行业编年。

## L4 卡片式 cards

- 第一眼：要点、工具、数据被装进一张张卡片，像产品页。
- 开篇：F1b 快讯卡（标签条 + 大标题 + 底部色带）或 F1e 编辑部封面。
- 章节进场：F3d 色块章头 / F3g 渐变圆角徽标，轻快。
- 引用/列表/图片：条目卡 F9a/F9b、数据卡 F9c、流程卡 F9d；图片可全宽。
- 收尾：签名卡；CTA 卡仅在原文有互动引导时加。
- 容器 `max-width:660px`；适用：工具盘点、测评、知识整理、信息密度高的文章。

## L5 海报式 poster

- 第一眼：大色块、大字、强冲击，像一张海报或一张 verdict 页。
- 开篇：F1f 深色开场或通栏反白 hero；正文区反而极干净。
- 章节进场：F3f 反白通栏 / F3h 衬线居中大字，全篇只允许一个「大」元素。
- 引用/列表/图片：判断用金句拉引文（F6c/F6d）；结论可用海报式大字块（F13 变体）。
- 收尾：verdict 收束 → 签名卡。
- 容器 `max-width:660px`；适用：观点文、趋势判断、评测结论、需要「一拍即合」的文章。

## L6 侧栏式 sidebar

- 第一眼：目录常驻一侧，正文在另一侧（浏览器预览）；公众号版目录退化为顶部静态卡。
- 开篇：眉题 → 标题区 → 目录（F2a/F2d，前 3–6 章）→ 引言。
- 章节进场：F3c/F3i（编号 + 英文标签），与目录编号呼应。
- 引用/列表/图片：结构块优先（表格、代码、列表），正文克制。
- 收尾：收尾线 → 签名卡。
- 容器 `max-width:660px`；适用：长教程、参考手册、工具文档（章节 ≥ 8）。

## L7 讲义式 lecture-notes

- 第一眼：像一页页纸面讲义——顶部栏目眉题系统、大标题、大字号正文，图解（重叠圆/大引号/高亮条/SUMMARY 卡）穿插，页脚页码感收尾。
- 开篇：顶部眉题系统（栏目名 · EN + 可选页码「01 / 09」）→ 大标题（讲义档 23px）→ 引言。
- 章节进场：F3b 水印大数字叠底版（浅色大数字 + 标题负 margin 叠后）或 F3h 衬线大字；章节像「页」。
- 图解：F6e 大引号引用（楷体）、M6 整句高亮条、F7e SUMMARY 结论卡、F9e 重叠圆对比，穿插在段落间。
- 收尾：SUMMARY/verdict 收束 → 收尾线 → 签名卡。
- 容器 `max-width:560–620px`；正文 17px、行高 1.9（讲义档）；适用：技术讲解、知识分享、课程讲义、深度教程。

## L8 报章式 newspaper

- 第一眼：一张报纸版面——报头眉线（刊号 · 日期 · 栏目）、大号报章标题、栏线分隔、灰度/纸色。
- 开篇：F15a 报头眉线 → 大标题（宋体/报章 22px 900）→ 引言。
- 章节进场：F3a 报章方块编号（实心方块 + 标题 + 底部栏线）或 F3c；章节像「版面分区」。
- 引用/列表/图片：栏线引用（F6a）、编号列表、图片细线框；图注小字。
- 收尾：收尾线 → 签名卡。
- 容器 `max-width:620px`；正文 15px / 行高 1.8；适用：深度评论、行业观察、新闻式解读。

## L9 信笺式 letter

- 第一眼：一封手写信——信头（称呼 + 问候语 + 日期戳）、大行高正文、落款签名。
- 开篇：F15d 信头（称呼 + 问候语 + F15b 日期戳）→ 引言。
- 章节进场：F3e 墨线方块或 F3h 衬线居中（轻），小节靠留白切换。
- 引用/列表/图片：楷体引用（F6e）、圆点列表、图片圆角。
- 收尾：「此致」+ 落款签名卡。
- 容器 `max-width:560px`；正文 16px / 行高 1.95（松）；适用：致读者、个人随笔、品牌信、书信体。

## L10 终端式 terminal

- 第一眼：一个终端窗口——深底 + 顶栏（红黄绿圆点 + 标题）+ 等宽字体 + 提示符开篇，像在终端里读完一篇文章。
- 开篇：F16a 窗口顶栏（圆点 + 窗口标题）→ 等宽大标题（浅色）→ F16b 提示符引言。
- 章节进场：F3i 终端标签（▸ 01 / TAG）；章节像「命令段落」。
- 引用/列表/图片：代码块 F12a 天然融入（与正文同一深底）；列表用 F8b 编号圆标或提示符行；引用少用。
- 收尾：`$ done` 提示符收束 → 收尾线 → 签名卡。
- 容器 `max-width:640px`；正文 14.5px / 行高 1.8；深色板；适用：技术长文、命令行教程、工具文档、程序员向文章。

## 规格速查

| 骨架 | 第一眼 | 开篇 | 章节进场 | max-width | 适用 |
|---|---|---|---|---|---|
| L1 单栏流 | 干净文字流 | 眉题+细线 | 线/数字/墨线 | 560–660px | 随笔/观点/长文 |
| L2 导读+章节流 | 先看导航卡 | 目录卡+引言 | 编号+英文标 | 660px | 教程/清单/方法论 |
| L3 时间线式 | 一条时间轴 | 眉题直进 | 大数字+竖线 | 560–660px | 演进史/复盘 |
| L4 卡片式 | 卡片页面 | 快讯卡/编辑部封面 | 色块/渐变徽标 | 660px | 盘点/测评/知识整理 |
| L5 海报式 | 大色块强冲击 | 深色开场/反白 hero | 反白通栏/居中大字 | 660px | 观点/趋势/评测结论 |
| L6 侧栏式 | 目录+正文 | 标题区+目录 | 编号+英文标 | 660px | 长教程/参考手册 |
| L7 讲义式 | 纸面讲义 | 眉题系统+大标题 | 水印数字叠底/衬线大字 | 560–620px | 技术讲解/知识分享/课程 |
| L8 报章式 | 报纸版面 | 报头眉线+大标题 | 报章方块/栏线 | 620px | 深度评论/行业观察/新闻解读 |
| L9 信笺式 | 一封手写信 | 信头+日期戳 | 墨线/衬线轻标 | 560px | 书信体/随笔/致读者 |
| L10 终端式 | 一个终端窗口 | 顶栏+提示符引言 | 终端标签 | 640px | 技术长文/命令教程/工具文档 |

## 规则

- 骨架决定「形状」，其余维度决定「皮肤」；两者自由组合，不互相锁定。
- 同一篇只走一条骨架；不把 L4 的卡片塞进 L1 的文字流，也不把 L5 的反白章头铺满全篇。
- 骨架与气质冲突时按 references/design-system.md 的冲突消解表处理（如 L5 海报式 × 人文书卷 → 保留居中大字、弱化色块）。
