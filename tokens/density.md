# 疏密档位（density）

三档间距基准。同一篇内所有间距统一取一档；装饰等级与密度成反比（紧 → L0/L1，松 → 可 L2/L3）。

## 松 loose

| 属性 | 值 |
|---|---|
| 容器 padding | 40–48px 上下 / 28–32px 左右 |
| 章节间距（h2 前） | 48–56px |
| 段落间距 | 20–24px |
| 正文行高 | 1.9–2.0 |
| 引用/图片 margin | 32px |
| 图片间距 | 32px |

适用：随笔、书卷、杂志感、品牌向。

## 中 medium（默认）

| 属性 | 值 |
|---|---|
| 容器 padding | 32px 上下 / 24–28px 左右 |
| 章节间距（h2 前） | 36–40px |
| 段落间距 | 14–18px |
| 正文行高 | 1.75–1.85 |
| 引用/图片 margin | 24px |
| 图片间距 | 24px |

适用：大多数观点文、科普、教程。

## 紧 tight

| 属性 | 值 |
|---|---|
| 容器 padding | 20–24px 上下 / 20px 左右 |
| 章节间距（h2 前） | 24–28px |
| 段落间距 | 10–12px |
| 正文行高 | 1.6–1.7 |
| 引用/图片 margin | 16px |
| 图片间距 | 16px |

适用：清单、数据、报告、工具盘点的长文（信息密度高时）。

## 原则

- 同一篇：段间距、图片间距、章节间距必须成比例，不允许忽大忽小。
- 松 ≠ 空：松密度时用章节间距分层，不要让页面像散沙。
- 紧 ≠ 挤：紧密度下限行高 1.6、段距 10px，低于此值直接返工。
- 标题与正文的距离 < 段间距（标题挂住正文），h2 上大下小。
