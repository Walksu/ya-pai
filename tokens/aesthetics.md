# 气质定义（aesthetics）

每种气质给出一句话定位、默认组合与设计要点。条目 id 用于产物文件名（如 `quiet-editorial`）。

各气质默认背景样式为「纯色 B1」（tokens/backgrounds.md），用户可在提问阶段改选其他档位或自由描述。

## 1. 安静编辑 quiet-editorial

- 定位：杂志内页般的克制，靠字与留白说话。
- 关键词：克制、留白、均衡、纸张、编辑感。
- 默认组合：暖米 + 衬线标题/无衬线正文 + L1 单栏流（窄）+ 中 + L1 细线。
- 适用：书评、随笔、深度观点、人物特写。
- 设计要点：
  - 正文 15–16px、行高 1.8–1.9；眉题 12px + letter-spacing 2px。
  - 标题字重 600 即可，不靠放大字号制造存在感。
  - 引用用左竖线；分隔线 1px 细线；全文强调 ≤ 每段 1 处。
- 反例：彩色卡片、大圆角、渐变、花哨分隔线。

## 2. 现代极简 modern-minimal

- 定位：产品文档般的干净利落。
- 关键词：干净、几何、秩序、科技、留白。
- 默认组合：冷灰或高对比 + 全无衬线 + L1 单栏流 + 松 + L0/L1。
- 适用：科技、产品、方法论、效率工具。
- 设计要点：
  - 大段留白，靠间距分层；h2 用字重 + 间距分隔，不靠装饰。
  - 列表去圆点（用间距）或方形 marker；数字/英文用无衬线。
  - 可加眉题标签制造结构（如「TUTORIAL / 教程」）。
- 反例：衬线大标题、纸感底色、引用卡片堆叠、圆角渐变。

## 3. 人文书卷 humanistic

- 定位：书页与笔墨的温度。
- 关键词：书卷、温润、慢、文学、文化。
- 默认组合：暖米 + 中文友好衬线（正文也用衬线）+ L1 单栏流（窄）+ 松 + L2 轻微色块。
- 适用：文学、历史、文化评论、长文深度阅读。
- 设计要点：
  - 正文可「首行缩进 2em + 无段距」或「段距式」，二选一。
  - 标题与正文同衬线家族；行高 1.9 以上。
  - 引用：左竖线 + accent-soft 浅底；高亮用极浅米底。
- 反例：无衬线正文、黑白高对比、圆角卡片堆叠、代码风眉题。

## 4. 冷冽理性 cool-rational

- 定位：图表与论文的冷静，先逻辑后温度。
- 关键词：理性、结构、数据、克制、条理。
- 默认组合：冷灰或深色 + 全无衬线或等宽点缀 + 适中/带目录 + 中/紧 + L0/L1（可 L2 色块辅助）。
- 适用：数据分析、报告、教程、逻辑拆解、工具对比。
- 设计要点：
  - 章节编号清晰（01/02/03）；列表、表格、代码块是主角。
  - 代码块深底 + 等宽字体；图注统一灰字左对齐或居中。
  - 避免暖色 accent；目录卡片适合此气质。
- 反例：花哨引用卡、暖米底、衬线标题、过度留白。

## 5. 温暖纸感 warm-paper

- 定位：一张有温度的纸，适合讲故事。
- 关键词：亲切、柔软、故事、生活、品牌。
- 默认组合：暖米或低饱和 + 宋体标题/黑体正文（或 无衬线标题+衬线正文）+ 适中/杂志感 + 松 + L2/L3。
- 适用：生活方式、情感、访谈、品牌内容。
- 设计要点：
  - 封面区：标题 + 引言放在 accent-soft 色块上（圆角 ≤ 12px）。
  - 拉引文 1–2 处：大号衬线、accent 色或浅底卡片。
  - 章节色点编号；结尾签名卡。
- 反例：深色背景、冷灰高对比、密集排版、代码块过多。

## 气质 ↔ 维度兼容提示

- 安静编辑与冷冽理性都可配「细线」，但暖色系 vs 冷色系决定冷暖。
- 人文书卷与温暖纸感都偏「暖」，区别：书卷靠衬线 + 缩进，纸感靠色块 + 卡片。
- 现代极简与冷冽理性都偏「冷/净」，区别：极简重留白，理性重结构（编号/目录/表格）。

## 版式人格（渲染人格）

气质不只决定颜色，还决定整篇的「排版语气」——标题结构、引用样式、列表标记、代码块要形成一致人格，不跨人格混搭。选组件时按下面这张表对齐：

表中的「章头人格」是各气质的**推荐默认标题风格**；标题风格作为独立维度（F3a–F3j）可被用户单独指定覆盖（如人文书卷也可以配渐变圆角徽标，冲突时按 design-system 冲突消解表处理）。

| 气质 | 章头人格 | 引用人格 | 列表人格 | 代码人格 | 正文基准 |
|---|---|---|---|---|---|
| 安静编辑 | 编号+细线 F3a / 墨线 F3e | 左竖线 F6a | 圆点/编号 F8a/F8b | 浅底细边 | 15–16px / 400–450 / 1.8–1.9 |
| 现代极简 | 水印大编号 F3b | 左竖线 F6a | 无圆点靠间距 | 浅底圆角 | 15–16px / 400 / 1.75–1.85 |
| 人文书卷 | 墨线 F3e / 编号细线 F3a | 左竖线 F6a / 拉引文 F6d | 圆点/编号 F8a/F8b | 浅底或深底 | 16px / 450 / 1.9（可首行缩进 2em） |
| 冷冽理性 | 大数字+竖线 F3c / 反白 F3f | 左竖线 F6a | 编号圆标 F8b | 深底圆角 | 15px / 400 / 1.7–1.8 |
| 温暖纸感 | 色块章头 F3d / 编辑部封面 F1e | 浅底引用 F6b | 药丸/圆点 F8c | 浅底圆角 | 16px / 400 / 1.8 |

正文基准参考（吸收自成熟公众号排版项目的实测基线）：

- 深度长文 / 信息密度高：正文 15px、字重 450、行高 1.68–1.75 最稳；更舒展可用 17px。
- 杂志 / 叙事类：16px、行高 1.8–1.9。
- 极简（minimal 一类）：15px、行高 2.0，靠大行高代替装饰。
- 标题层级建议比例：h2 19–20px、h3 17–18px、眉题 11–12px + letter-spacing 2px，与正文基准成阶梯。
