# 组合画廊示例短文

这是一篇用于组合画廊的示例短文，覆盖段落、章节、引用、列表、行内代码与代码块等常见元素，方便对比不同组合的排版效果。

## 第一章：关于留白

好的排版不靠堆装饰，而靠结构。段落间距、章节间距、行高统一，读者的视线就有节奏。

> 留白不是空，是让内容呼吸的地方。

正文里的**关键判断**需要被看见，列表也一样：

- 层级要清楚
- 间距要统一
- 强调要克制

## 第二章：关于节奏

密集文字之后需要视觉喘气。图片、引用、卡片都是呼吸点，但全篇只允许一个“大”元素。

```bash
ya-pai render --layout guided --title tech
```

`code --flag` 这种行内代码也要有它的位置。

## 第三章：关于收尾

结尾应该克制。一行收尾线，一张签名卡，不虚构互动引导。
